# CrudSimplesTDD
Projeto acadêmico em Java com foco em testes unitários utilizando TDD, generics e arquitetura orientada a serviços. Não utiliza banco de dados — simulação feita com armazenamento em memória.

## 🚀 Tecnologias Utilizadas

- Java SE 21
- JUnit 4
- Programação Orientada a Objetos (POO)
- TDD (Test-Driven Development)
- Generics (DAO e Services)
- Mocks em memória (sem banco de dados)
- IDE: Spring Tool Suite 4 (STS4)

## 🧪 Funcionalidades Implementadas

- Cadastro de Cliente
- Cadastro de Produto
- Registro de Vendas
- Cálculo de Total da Venda
- Testes de salvar, atualizar, excluir e buscar
- Testes automatizados com JUnit
